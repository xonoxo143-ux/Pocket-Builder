# Contributing

Keep changes aligned with the product specification and security model.

Before submitting a change:

- add or update tests for pure source, archive, recipe, and workspace logic
- keep project-controlled code out of the application process
- do not add a dependency on Termux or another terminal application
- document new toolchain downloads, licenses, versions, and integrity checks
- keep the primary UI stage-oriented rather than terminal-oriented
- never commit signing keys, local SDK paths, toolchain caches, APKs, or project workspaces
