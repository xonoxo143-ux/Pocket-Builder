# Interface direction

PocketBuild uses a native, stage-oriented interface rather than a terminal-first interface.

## Phone navigation

- Home
- Projects
- Builds
- Toolchains
- Settings

## Large-screen navigation

The same destinations move to a navigation rail. Project details and build status can later use a two-pane layout on tablets and foldables.

## Core screens

### Home

Open a source, see recent work, toolchain readiness, and the latest build.

### Project inspection

Show detected type, project root, compatibility, warnings, required packs, and the next safe action.

### Build

Show named stages, current task, progress, useful warnings, cancel action, and a collapsible detailed log.

### Toolchains

Show exact installed version, health, size, source, update state, verify, repair, and remove actions.

Raw process output remains available for diagnosis but is not the main product surface.
