# Security

PocketBuild handles untrusted project archives and executable build definitions.

Do not submit real signing keys, passwords, private tokens, or proprietary project archives in public issues.

Security-sensitive reports should include the affected commit, Android version, project type, and a minimal reproduction that does not contain secrets. Reports involving archive traversal, toolchain verification bypass, signing-key exposure, unintended file access, or command execution should be treated as high priority.
